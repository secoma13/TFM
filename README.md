## Master's Thesis
# Moment map equations in Kähler geometry and gauge theory

This repository contains the LaTeX code for my Master's Thesis. This thesis was written at the Complutense University and supported by a Severo Ochoa Grant during the academic course 2025-2026.

# Abstract
We present an account of the Hitchin-Kobayashi correspondence for principal bundles over compact Riemann surfaces with connected structure group. We sketch a proof of
the correspondence, and present the moment map picture associated with some level of detail for the general case of compact Kähler manifolds, including a rigorous proof of the

Marsden-Weinstein theorem for Hamiltonian actions of Banach-Lie groups on Banach-manifolds. We also give a proof of the Chern-Singer correspondence, and we see how the Hitchin-Kobayashi correspondence can be seen as an infinite-dimensional version of the Kempf-Ness theorem. Finally, we study the correspondence for principal bundles with non-connected structure group, and we sketch how it can be reduced to a correspondence for twisted bundles with connected structure group.
